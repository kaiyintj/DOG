四足机器人开放词汇语义建图与语言导航算法创新点说明
========================================================

版本：基于当前 /home/yk/ws/src/semantic_mapping 实现
用途：硕士小论文选题说明、方法章节初稿、开题/中期汇报和实验设计依据


一、项目当前解决的问题
----------------------

本项目面向四足机器人在未知环境中的在线作业，目标是让机器人完成以下闭环：

1. 利用激光雷达和IMU进行在线定位与几何建图；
2. 利用相机和视觉语言模型理解道路、建筑、树木、人员、车辆等语义；
3. 把二维图像语义投影并融合到三维激光体素地图；
4. 接收“person”“car”等自然语言目标；
5. 在语义地图中定位目标，并选择安全、可到达的接近位置；
6. 通过Nav2规划路径，同时根据前方语义不确定性调节机器狗速度；
7. 最终从Gazebo和Bag仿真迁移到云深处绝影Lite3激光版实机。

完整数据流为：

FAST-LIO定位建图
    -> 激光点云与相机图像时空关联
    -> CLIP开放词汇语义特征
    -> 可靠度感知Dirichlet语义体素融合
    -> 语义点云、认知不确定性和二维语义代价地图
    -> 语言目标空间聚类与安全接近点选择
    -> Nav2路径规划
    -> 不确定性感知速度调节
    -> 四足机器人运动控制


二、建议使用的算法名称
----------------------

中文名称：

面向四足机器人运动扰动的可靠度感知开放词汇Dirichlet语义体素建图与导航方法

英文名称建议：

Motion-Reliability-Aware Open-Vocabulary Dirichlet Semantic Voxel Mapping
for Quadruped Language Navigation

英文缩写可暂定为：MR-OVSM

当前代码节点仍然叫 ga_bsvm_node，这是为了保持ROS2接口兼容。论文中不建议继续把
GA直接解释为严格的“Gait-Aware”，因为当前使用的是机身IMU运动强度和振动偏差，尚未
使用足端接触状态或关节反馈恢复严格的支撑相/摆动相。现阶段更准确的表述是
Motion-Reliability-Aware，即“运动可靠度感知”。


三、核心创新点概览
------------------

当前可以形成三层贡献：

核心创新点1：面向四足运动扰动的多因素观测可靠度模型。

核心创新点2：带单帧证据上限和遗忘机制的多分类Dirichlet语义体素融合。

核心创新点3：基于空间支持度、开放词汇相似度和可通行性的语言目标决策。

辅助创新点：基于语义不确定性的连续速度调节与安全导航闭环。

其中，创新点1和创新点2应当合并作为论文的“主要方法贡献”；创新点3适合作为由语义
地图走向语言导航的“任务层贡献”；速度调节适合作为系统闭环和安全性增强，不宜单独
宣称为完整的主动感知理论。


四、创新点1：多因素观测可靠度建模
----------------------------------

1. 现有简单方法的问题

普通语义建图通常把每一帧网络输出以相同权重写入地图。但是四足机器人行走时会产生
明显的周期振动、机身旋转、图像模糊和点云投影误差。相同的CLIP预测，在机器人静止、
稳定行走、急转弯和强烈振动时，其可信度并不相同。

此外，远距离激光点、图像边缘点、局部稀疏点以及语义熵很高的预测，也不应该获得与
近距离、图像中心、局部稠密且语义明确的观测相同的融合权重。

2. 当前提出的联合可靠度

对第i个投影点，在时刻t定义总可靠度：

    w_i^t = q_motion^t
            * q_density_i^t
            * q_range_i^t
            * q_view_i^t
            * q_semantic_i^t

其中每一项都归一化到[0,1]。

2.1 运动可靠度

在点云时间戳附近的IMU窗口内，计算角速度均方根和加速度模长相对重力的偏差：

    omega_rms = sqrt(mean(||omega||^2))

    delta_a_rms = sqrt(mean((||a|| - g)^2))

运动可靠度定义为：

    q_motion = exp(-0.5 * [
                    (omega_rms / tau_omega)^2
                    + (delta_a_rms / tau_a)^2
                 ])

最后限制在[q_motion_min, 1]范围内，防止运动时完全停止建图。

与旧实现相比，新方法删除了根据ROS绝对时间生成余弦相位的做法。旧相位没有与真实
足端触地事件锁相，可能随机把正确观测权重降为零。新方法与传感器时间戳对齐，并直接
描述导致投影误差和图像模糊的机身运动强度。

对应代码：

    semantic_mapping/ga_bsvm_node.py
    compute_motion_reliability()

关键参数：

    imu_window_sec
    motion_angular_scale
    motion_accel_scale
    motion_min_reliability
    imu_gravity

2.2 点云局部密度可靠度

以点为中心统计固定半径邻域内的点数rho：

    q_density = 1 - exp(-rho / tau_rho)

局部越稀疏，投影和表面估计越不稳定；点数增加时可靠度逐渐饱和，避免简单线性权重
对超密集区域过度奖励。

2.3 距离可靠度

设激光点到传感器距离为r：

    q_range = exp(-(r / tau_r)^2)

远距离点通常角分辨率更低，对外参误差更敏感，因此获得更小权重。

2.4 图像视场可靠度

设投影像素到图像中心的归一化径向距离为d_img：

    q_view = clip(1 - lambda_view * d_img^2, q_min, 1)

图像边缘通常存在更大的畸变和标定残差，所以边缘投影点被适当降权。

2.5 语义可靠度

先计算CLIP类别概率p及其归一化熵：

    H(p) = -sum_k p_k log(p_k)

    H_norm = H(p) / log(K)

语义可靠度为：

    q_semantic = c_min + (1 - c_min) * (1 - H_norm)

当各类别概率接近均匀分布时，语义观测权重降低；当某个类别明显占优时，观测权重
升高。c_min保证模糊观测仍保留少量证据，而不是被完全删除。

3. 这一创新点的意义

该模型不是只依靠神经网络置信度，而是联合机器人运动状态、激光几何质量、相机投影
位置和语义分布，专门针对四足平台运动造成的跨模态投影不稳定问题。

需要通过消融实验证明：加入q_motion后，行走和转弯阶段的错误语义写入减少；加入完整
可靠度后，地图mIoU、类别稳定性和概率校准优于等权融合。


五、创新点2：可靠度加权的Dirichlet体素证据融合
------------------------------------------------

1. 旧多分类log-odds方法的问题

旧实现把每一个类别概率分别转成二元log-odds：

    L_k = log(p_k / (1 - p_k))

然后对K个类别分别累加。对于六分类问题，大多数p_k都小于0.5，因此多个类别的
log-odds会同时向负方向累积并发生截断。再分别做sigmoid和归一化，并不是严格的
多分类贝叶斯后验，长期融合可能出现所有类别一起饱和的问题。

2. CLIP概率校准改进

原实现直接使用图像特征与文本特征的余弦相似度作为logits。CLIP训练时实际使用了
可学习温度，因此当前方法恢复模型的logit_scale：

    z_k = s_clip * cosine(f_image, f_text_k)

    p_k = softmax(z)_k

同时对每个类别使用多个文本模板，例如：

    a photo of a person.
    a photo of the person.
    a person in the scene.

多个文本特征归一化后求平均，降低单一提示词对分类结果的影响。

对应代码：

    semantic_mapping/clip_node.py
    encode_texts()

关键参数：

    logit_scale
    text_templates

3. 单帧体素聚合

同一帧中，一个物体表面可能在同一体素内产生很多激光点。这些点不是相互独立的观测，
如果逐点更新，会导致点越密集的区域置信度越高，而不是观测次数越多的区域置信度越高。

因此先在每帧内部对落入体素v的点聚合：

    p_bar_v^t = sum_i(w_i^t * p_i^t) / sum_i(w_i^t)

该帧对体素的总证据为：

    e_v^t = min(sum_i w_i^t, e_frame_max)

无论该体素一帧收到10个点还是100个点，单帧证据都有上限，避免相关点云重复“刷票”。

4. Dirichlet证据递推

每个体素维护K维Dirichlet参数alpha_v。先对历史证据执行轻微遗忘，再加入当前帧证据：

    alpha_v^t = alpha_0
                + lambda_decay * (alpha_v^(t-1) - alpha_0)
                + eta * e_v^t * p_bar_v^t

其中：

    alpha_0       为均匀先验；
    lambda_decay  为历史证据保留比例；
    eta           为证据强度；
    e_v^t         为当前帧可靠证据量；
    p_bar_v^t     为当前帧平均类别分布。

类别后验均值为：

    P(y=k | v) = alpha_vk / sum_j alpha_vj

同时设置max_total_evidence。当总证据超过上限时，在保持类别比例的条件下缩放历史证据，
避免地图置信度无限增大，使动态目标或早期错误永远无法被后续观测修正。

对应代码：

    semantic_mapping/voxel_map.py
    VoxelMap.update()

关键参数：

    evidence_prior
    evidence_strength
    evidence_decay
    max_frame_evidence
    max_total_evidence

5. 两类不确定性的统一表示

当前地图同时考虑：

    语义模糊性：类别后验的归一化香农熵；
    证据不足性：Dirichlet总证据过少带来的认知不确定性。

定义：

    U_entropy = H(P) / log(K)

    U_evidence = K / sum_k alpha_k

综合不确定性：

    U_v = lambda_u * U_entropy
          + (1 - lambda_u) * U_evidence

体素置信度：

    C_v = 1 - U_v

这样可以区分两种情况：

    情况A：只观察了一次，但网络输出非常尖锐；
    情况B：经过多次一致观测，类别后验稳定。

普通softmax熵可能认为两者同样可信；Dirichlet证据项会让情况A保持较高认知不确定性。

对应参数：

    uncertainty_entropy_weight

6. 双轨语义表示

每个体素同时保存：

    K维Dirichlet类别证据，用于稳定语义分类、熵计算和Nav2代价地图；
    归一化CLIP特征，用于固定词表之外的自然语言查询。

这使地图同时支持“可解释的有限类别安全规则”和“开放词汇检索”。有限类别后验负责
road/person/car等导航安全语义，CLIP特征负责“穿红衣服的人”“路边的车辆”等开放表达。


六、创新点3：空间支持的语言目标聚类与安全接近决策
------------------------------------------------------

1. 单体素最大相似度的问题

旧方法在全部体素中直接选择CLIP余弦相似度最大的单个体素。一次错误投影、墙面反光或
粗图像块都可能产生偶然高分，因此曾出现查询car却把墙边体素作为目标的情况。

2. 体素候选评分

对满足最小观测证据的体素，计算语言相似度：

    s_clip(v,q) = cosine(f_v, f_q)

若查询词属于安全词表，还同时使用Dirichlet类别后验：

    s_v = lambda_f * s_clip(v,q)
          + lambda_c * P(y=q | v)

候选必须满足：

    体素累计证据大于query_min_weight_sum；
    CLIP相似度大于query_min_similarity；
    固定类别查询的后验概率大于query_min_class_prob。

3. 空间聚类

在候选体素二维位置上建立KD树，把距离小于query_cluster_radius_m的体素连接成空间簇。
只有同时满足最小体素数量和最小证据量的簇才会进入目标竞争。

对簇G计算：

    S_sem(G) = 0.8 * weighted_mean(s_v)
               + 0.2 * max(s_v)

    S_support(G) = min(log(1 + E_G) / log(31), 1)

    J(G) = S_sem(G)
           + lambda_support * S_support(G)
           - lambda_distance * D(robot, G)

最终选择J最大的空间簇，而不是一个孤立体素。

4. 类别尺寸约束

粗粒度图像块可能把整面墙都赋予person类别。当前方法为不同类别设置最大水平范围：

    person最大水平范围默认1.5 m；
    car最大水平范围默认5.0 m；
    road/building/tree等大范围类别不使用严格尺寸限制。

因此，即使墙面簇有很高分数，只要其水平尺寸明显不符合person目标，也会被拒绝。

关键参数：

    query_cluster_radius_m
    query_cluster_min_voxels
    query_cluster_min_evidence
    query_cluster_support_weight
    query_distance_weight
    query_class_max_extent_m

5. 安全接近点而不是物体中心

person、car、building和tree在语义代价规则中属于障碍类。机器人不应把目标物体表面作为
Nav2终点，而应在目标附近寻找road体素。

候选road体素必须满足：

    与目标距离位于[d_min, d_max]；
    周围query_clearance_radius_m范围没有高代价语义体素；
    体素观测证据和置信度满足要求。

候选接近点代价为：

    J_approach = |d_object - d_desired|
                 + lambda_robot * d_robot
                 + lambda_height * delta_z
                 - lambda_confidence * C_v

选择代价最小的road体素作为导航终点，并设置终点朝向，使机器人到达后面向目标。

如果实机配置中找不到安全接近点，则不发布目标，不允许使用物体表面作为不安全兜底。

对应代码：

    semantic_mapping/ga_bsvm_node.py
    select_query_cluster()
    find_approach_goal()
    query_feature_cb()


七、辅助贡献：不确定性感知速度调节
------------------------------------

1. 路径不确定性

从Nav2当前路径中截取机器人前方lookahead_dist米的路径段，在路径周围搜索语义体素，
计算综合不确定性的平均值，并转换成与香农熵同量纲的H_bar。

2. 连续速度缩放

归一化路径不确定性：

    u_path = clip(H_bar / H_max, 0, 1)

目标速度比例：

    alpha_target = alpha_min
                   + (1 - alpha_min) * (1 - u_path)

高置信区域接近原速度，未知或高不确定区域降低线速度。

3. 控制稳定性改进

当前实现增加两层平滑：

    对H_bar使用指数滑动平均；
    对相邻控制周期的alpha变化设置max_scale_step上限。

默认只缩放线速度，不缩放角速度。旧实现同时压低角速度，在高不确定弯道上可能导致
机器人无法正确转向和跟踪Nav2路径。若实机需要限制转向，可启用角速度缩放，但设置
angular_min_speed_ratio保证最低转向能力。

新增诊断话题：

    /path_entropy
    /semantic_speed_scale
    /perception_mode

需要注意：当前功能准确名称应为“不确定性感知速度调节”，而不是完整主动感知。
真正的主动感知还需要根据预期信息增益主动选择观察点、转头方向或探索前沿。


八、哪些属于算法创新，哪些属于工程贡献
----------------------------------------

可以作为算法创新描述：

1. 四足运动、点云几何、图像投影和语义熵联合可靠度；
2. 单帧证据受限的可靠度加权Dirichlet语义融合；
3. 语义熵与Dirichlet证据不足性联合不确定性；
4. 开放词汇体素特征与有限类别安全后验的双轨地图；
5. 空间簇支持、类别尺寸和安全接近约束联合的语言目标选择。

属于工程贡献，不能单独宣称为原创算法：

1. 使用FAST-LIO提供里程计和点云地图；
2. 使用OpenCLIP提取视觉语言特征；
3. 使用Nav2进行路径规划；
4. ROS2话题参数化、QoS修复和launch整理；
5. 同时支持M2DGR Bag、Gazebo Livox和Lite3实机配置；
6. RViz语义点云和代价地图显示。

论文可以把工程内容写成“系统实现与平台适配”，但不应把直接使用的开源模块列为算法
创新点。


九、与常见基线方案的区别
------------------------

基线A：单帧CLIP投影

    只显示当前帧语义，不做时序融合；容易闪烁，无法形成稳定地图。

本方法：

    使用可靠度加权的多帧Dirichlet证据，输出后验和不确定性。

基线B：所有观测等权平均

    静止和剧烈运动时的观测权重相同；密集点区域天然获得更多权重。

本方法：

    根据运动、密度、量程、视场位置和语义熵加权，并限制单帧最大证据。

基线C：逐类别二元log-odds

    对多分类概率进行独立二元更新，类别之间缺少严格的概率竞争关系。

本方法：

    使用一个K维Dirichlet分布表示完整类别后验，并显式建模证据量。

基线D：最高相似度体素作为目标

    容易被孤立误检、墙面投影污染和远距离噪声影响。

本方法：

    要求目标形成空间簇，并加入证据量、尺寸、距离和类别概率约束。

基线E：直接导航到目标坐标

    person和car位置本身是障碍，Nav2可能拒绝规划或发生碰撞。

本方法：

    搜索目标附近满足语义类别、间距和净空要求的road接近点。


十、论文可以采用的贡献表述
--------------------------

推荐写成以下三点：

贡献1：提出一种面向四足机器人运动扰动的跨模态观测可靠度模型，联合机身IMU运动、
激光局部几何质量、传感器量程、图像投影位置和视觉语言预测熵，对二维语义到三维地图
的观测质量进行在线估计。

贡献2：提出一种单帧证据受限的可靠度加权Dirichlet语义体素融合方法，同时建模类别
模糊性和证据不足性，并在体素中联合维护有限类别后验与开放词汇视觉语言特征，以提高
四足机器人运动状态下语义地图的稳定性和可查询性。

贡献3：设计一种空间支持与可通行性约束的语言目标决策方法，通过体素聚类、类别尺寸
约束、语义置信拒识和安全接近点搜索，将开放词汇目标定位结果转化为Nav2可执行目标，
并结合路径不确定性完成速度自适应导航。

在尚未完成对比实验前，论文中应使用“提出”“设计”“实现”等表述，不应直接使用
“首次”“显著优于现有方法”或“达到最先进水平”。这些结论必须由文献检索和定量实验
支持。


十一、必须完成的实验设计
------------------------

1. 语义建图对比

至少包含：

    M0：单帧CLIP投影；
    M1：多帧等权平均；
    M2：原始多分类log-odds；
    M3：Dirichlet融合，不使用可靠度；
    M4：Dirichlet + motion可靠度；
    M5：完整联合可靠度Dirichlet方法。

指标：

    体素或点级mIoU；
    各类别IoU；
    Overall Accuracy；
    NLL或Brier Score；
    ECE概率校准误差；
    地图标签翻转率；
    不同运动速度下的语义稳定性；
    单帧处理时间、CPU/GPU占用和地图内存。

2. 运动可靠度消融

设置至少三种机器人状态：

    静止；
    正常行走；
    转弯或高振动运动。

比较等权融合与运动可靠度融合，记录错误语义写入数量、地图mIoU和重投影一致性。

实机阶段最好进一步记录Lite3关节状态或足端接触状态。如果能够证明IMU可靠度与真实
步态相位、图像模糊或投影误差存在统计关系，就可以把“Motion-Aware”进一步强化为
“Gait-Aware”。

3. 语言目标检索实验

对person、car、tree、building和若干开放描述分别测试：

    Top-1目标定位成功率；
    目标位置误差；
    墙面误检率；
    无目标场景拒识率；
    查询到目标的计算时间；
    单体素方法与空间聚类方法的差异。

必须专门统计“查询person/car却落在墙面”的次数，以证明空间簇和尺寸约束的价值。

4. 导航实验

指标：

    Success Rate；
    SPL；
    实际路径长度；
    规划失败次数；
    碰撞次数；
    与目标最终距离；
    平均速度和任务时间；
    最小障碍距离；
    高不确定区域的速度变化。

对比：

    直接导航到最高分体素；
    使用目标空间簇但不选择安全接近点；
    完整空间簇 + 安全接近点；
    固定速度；
    不确定性速度调节。

5. 仿真与实机规模建议

Gazebo至少设计3类场景，每类包含多个随机起点、目标位置和遮挡条件。每个实验设置建议
重复10次以上，报告均值和标准差，不能只展示一次成功视频。

Lite3实机至少完成：

    静止建图；
    行走建图；
    person目标查询与接近；
    car或其他大目标查询与接近；
    无目标查询拒识；
    高、低不确定区域速度对比。


十二、当前代码验证情况
----------------------

已经完成的验证：

1. Dirichlet一致观测能够提高正确类别概率；
2. 同一帧100个相关点不会比1个点产生无限大的额外证据；
3. 均匀语义即使积累较多证据仍保持高语义不确定性；
4. 多帧开放词汇特征融合后保持归一化；
5. person查询能够拒绝水平范围明显类似墙面的高分大簇；
6. Python语法检查通过；
7. 三套YAML配置检查通过；
8. semantic_mapping包colcon构建通过；
9. 标准ROS2 launch参数解析通过。

测试文件：

    src/semantic_mapping/test/test_voxel_map_algorithm.py
    src/semantic_mapping/test/test_query_selection.py


十三、当前仍然存在的限制
------------------------

1. 当前CLIP语义来自规则图像块，不是像素级开放词汇分割。较小目标仍可能与背景处于
   同一图像块，造成语义外溢。后续可比较更密网格、重叠窗口或开放词汇分割模型。

2. CLIP结果话题当前没有和源图像组成一个带统一Header的自定义消息。节点使用最新
   logits/features，推理延迟较大时可能与当前投影图像存在时间偏差。正式实验前建议加入
   带时间戳的语义观测消息或缓存匹配机制。

3. 运动可靠度目前根据机身IMU估计，不是严格步态相位估计。若论文强调Gait-Aware，
   需要接入Lite3足端接触、关节位置或控制器步态状态。

4. 当前“主动感知”只实现路径不确定性降速，没有主动选择最佳观察方向或探索前沿。
   若要形成第二篇或更强论文，可加入基于预期信息增益的主动视点选择。

5. 语义代价地图使用固定安全类别。开放词汇查询可以定位任意文本，但任意类别的安全
   属性仍需要规则、语言模型或可供性模型判断。

6. Lite3配置中的相机内参和雷达到相机外参仍是占位值。实机语义建图前必须完成联合
   标定，否则算法改进会被外参误差掩盖。

7. 当前系统存在SciPy与NumPy版本告警。正式实验应固定Python依赖版本和ROS2环境，
   保证所有数据可复现。


十四、后续最值得加强的方向
--------------------------

优先级1：实现CLIP结果与相机/点云的严格时间戳关联。

优先级2：在Gazebo建立自动评价脚本，生成mIoU、检索成功率、SPL和碰撞统计。

优先级3：完成Lite3相机内参和雷达-相机外参标定。

优先级4：读取Lite3足端接触或关节状态，把运动可靠度升级为真实步态相位可靠度。

优先级5：加入基于信息增益的主动观察点或探索前沿选择，使“主动感知”名副其实。


十五、最终定位
--------------

当前项目已经从“FAST-LIO + CLIP + Nav2的工程组合”升级为具有独立算法结构的系统：

    可靠度估计
        -> 受限证据Dirichlet融合
        -> 双源不确定性
        -> 空间支持语言目标
        -> 安全接近决策
        -> 不确定性导航控制

其中最有论文价值、也最符合四足机器人特点的主线是：

“四足运动扰动条件下，如何根据跨模态观测可靠度构建稳定、可校准、可用语言查询的
三维语义地图，并将查询结果安全转换为在线导航目标。”

目前的方法已经具备可写成论文方法章节的基础，但论文创新是否成立，最终取决于严格
的基线对比、消融实验、统计结果和Lite3实机验证，而不是只取决于系统能否运行。
