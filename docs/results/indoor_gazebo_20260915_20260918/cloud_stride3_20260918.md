上次 20260916_095040_sliding_tf_check 导航实时率约 0.411、墙钟 101.28 秒、减速比例样本均值 0.465。两次选择的 goal、路线不同，录制话题也不同：上次录导航点云，本次录 posterior/语义点云/熵。因此不能把耗时变化归因于 stride，也不能从 bag 体积推导优化效果。本次没有 CPU/GPU 采样，无法证明 GA-BSVM CPU 下降。

结论：一次导航功能与停止行为通过；没有证明性能改善。后续性能比较应统一录制和建图流程、固定目标，并补进程资源采样。碰撞率、目标语义正确性、多实例回退仍未独立验收。
