## 检查证据

- 17.74 秒内 LiDAR 177 帧（9.9996 Hz）、IMU 3,549 帧（200.0004 Hz）、彩色
  图像和 CameraInfo 各 266 帧（14.9893 Hz）。四路 Header 无零时间戳或倒退，
  图像与内参在 1 ms 内配对率 100%；LiDAR 到最近图像 Header 差 p99 为 33.30 ms。
- 三个采样帧分别有 1,278、1,442、1,538 个雷达点进入画面，约为原始帧点数的
  6.31%、7.15%、7.82%；CameraInfo 与图像 Header 完全相同，畸变系数为零。
- IMU 角速度模长 p95 为 0.0238 rad/s，第 40 与 220 帧图像平均绝对像素差
  约 1.38/255，与采样期间画面基本稳定一致。
- 三张图像分别在电脑 RTX 5070 Laptop GPU 上运行缓存的
  `nvidia/segformer-b0-finetuned-ade-512-512`，单次命令各约 2.9–3.0 秒，
  包括模型加载，不代表持续实时吞吐量。
- 雷达—相机投影采用本次 CameraInfo 与
  `/home/yk/ws/src/semantic_mapping/config/semantic_mapping_lite3_real.yaml` 中的
  2026-09-01 外参候选；当前实时 TF 中仍无正式 LiDAR—相机连接。

这些证据与“低机位、椅子主体在画面上缘或被遮挡，使类别识别失败”一致，但本次同时
改变了距离和遮挡，不能把相机高度认定为唯一原因。继续在类似视角反复录包没有明显
收益。若仅做进一步静止识别诊断，应让完整目标进入当前相机与雷达共同视野；若调整
相机安装高度或俯仰角，则旧外参候选失效，必须重新完成雷达—相机标定和投影验收。

本轮没有运行 FAST-LIO、GA-BSVM 完整 posterior 融合、Nav2、Goal Bridge 或底盘
执行端，也没有发送运动指令。继续保持
`projection_calibration_verified=false`、`goal_bridge_enabled=false`、
`MOTION_READY=NO`。
