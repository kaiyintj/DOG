# 语义体素观测预算

日期：2026-10-07。实现位于 [VoxelMap](../semantic_mapping/runtime/voxel_map.py)，
领域词汇见 [CONTEXT](../CONTEXT.md)。这是当前实现与受控验证说明，尚未完成真实输入上的融合收益比较。

## 规则与目的

同一体素、同一次投影包含 N 个可靠度有限的点。可靠度 r_i 截为 [0,1]；零可靠度也
参与质量均值，避免先删弱点再计算均值而抬高质量。非有限可靠度不参与。

```text
类别分布 p = sum(r_i * p_i) / sum(r_i)
观测质量 q = sum(r_i) / N
有限点支持 b = min(N, max_frame_evidence)
本次预算 e = b * q
有效贡献 e_eff = e * s(观测间隔) * 延迟衰减
alpha += evidence_strength * e_eff * p
```

没有正权重时不创建体素。颜色与特征仍使用可靠度加权均值；`weight_sum`、
`feature_weight_sum`、`color_weight_sum` 使用同一个 e_eff，各自保留既有有限权重上限。
`evidence_strength` 仅缩放类别证据。总 alpha 上限与历史证据衰减保持原有规则。

例如 20 或 200 个同类点，支持上限 3 时，质量 0.2 的预算均为 0.6，质量 1.0 的预算
均为 3。继续增加同质量点不能超过有限支持；这些数值不是识别正确率或独立样本数。
密度仍只由既有可靠度因子计权，本规则没有再次将局部密度乘入预算。

## 历史老化与观测支持分开

启用时间衰减时，历史证据依据点云采集时间连续指数衰减；剪枝时间已经晚于迟到观测时，只把新贡献
衰减到相同地图时间，避免历史二次衰减。源图像时间只用于同源识别与短间隔支持。
处理到达时间不替代任何传感器时间。普通剪枝遇到略落后的 `/clock` 时保留已有衰减
时间下限，不能重锚后让下一帧重复老化。

CARLA 六张消融地图记录已处理 LiDAR 的共同终点，包含没有匹配 RGB 的帧；报告前
一次性把未再次可见的体素老化到该终点。此步骤不删除体素、不增加观测或 GT 支持，
报告中的 `voxel_evaluation_time_sec` 保存各 offset 的终点。

支持间隔 h 最多为 `evidence_decay_reference_sec`（默认 0.1 s）。参考保留率 d 为
`evidence_decay`，0 < d < 1 时使用：

```text
h = min(观测间隔, reference_sec)
s(h) = (1 - d ** (h / reference_sec)) / (1 - d)
```

h=0 不注入，h 达到参考周期后 s=1。d=1 时 s=h/reference_sec，d=0 时每次正间隔
只保留当前观测。首次源观测按一份预算接纳。相同体素的 1、10、100 秒空窗都只允许
重现时本次一份预算；启用衰减时，空窗期间的历史按完整时间衰减。

2026-10-06 按当前静态室内实验假设，`semantic_mapping_sim_indoor.yaml` 使用
`evidence_decay: 1.0`、`voxel_ttl_sec: 0.0`：视线转移或遮挡不降低历史支持，也不因
300 秒未重见删除体素。没有新观测仍不会增加证据；同源去重、每次质量预算、总 alpha
上限 200、30 m 半径和 250000 个体素的容量限制保持。新源观测仍可改变类别，不把旧
判断冻结。其它三个 preset、通用 VoxelMap 默认值和 CARLA 对照保持原时间衰减。

现有 `last_observed_at_sec` 保留观测时间；静态室内不因年龄单独强制复查。传感器/TF

## 源图像贡献归属

`VoxelMap.update(..., source_id=(camera_id, image_stamp_ns))` 接收相机身份与整数源图
纳秒时间。ROS adapter 从已经检查同帧的 RGB Header 提取它，随投影数据与历史 TF
重试队列保存；三条 CLIP、完整 posterior、hard-mask 路线都传递相同信息。
CARLA adapter 从实际选中的历史 RGB 记录提取源时间；六种体素消融共享源身份。

每个体素、每个相机保存最多 `source_history_size` 个源时间（默认 32）和单调淘汰水位：

- 已保存的源时间：拒绝重复贡献，也不刷新 TTL、颜色、特征或观测计数。
- 窗口内未见过的旧源：允许贡献，按距最近已保存源时间的间隔做短周期归一化。
  点云时间递增而源图像乱序，是近似同步可达的情况；这不会重置历史衰减时钟。
- 更早于或等于已淘汰水位的源：保守拒绝，避免缓存淘汰后重复源重新累计。
- 同源图像首次覆盖的新体素：没有该体素的历史贡献，仍可接纳。
- 剪枝删除体素时，源状态一起释放；重新创建的体素没有已删除的历史证据。

内存按体素数、固定相机数量及源历史上限有界；运行中的 ROS 与 CARLA 各使用一个固定
相机身份。32 是近期源记录数量，不是秒数，超出窗口的唯一旧源也可能被保守拒绝。
调整传感器频率、同步或重试窗口时，应重新确认该上限，不宣称无限历史精确去重。

无源身份但有时间戳的直接数学调用，仍按点云间隔作有界支持归一化；没有时间戳的
既有调用保留每次一步衰减。这些调用不能提供源图像去重保证，两个实际 adapters 已补齐身份。

ROS adapter 监听时钟自身的负向回跳通知，在回跳发生时调用 `reset_clock`，统一重锚
观测与衰减时钟、清除旧源历史、同步器输入队列、IMU 缓存、待重试帧和旧动态 TF，
保留地图证据与静态 TF。清空同步器可避免新 epoch 的较小时间戳被旧满队列不断淘汰。
当前 ROS 时间暂时落后点云时间不能触发重置。源身份调用的迟到观测仍衰减到已有地图
时间；时钟重启必须显式调用 `reset_clock`。无源身份的既有数学调用保留自动回退契约。
历史 TF 不可用的帧仍等待有界重试，不使用最新 TF 代替历史 TF。

点云顺序与语义输出时间分别维护：`latest_observation_ns` 拒绝较旧点云，即使上一帧
全部被去重拒绝也保留此保护；`latest_fused_observation_ns` 只随实际正贡献推进。
`update` 的新建/更新数量只统计收到正贡献的体素，地图 revision 仍记录老化与源状态
变化。全帧没有贡献时不发布新时间的语义/不确定性点云，也不触发查询重试；同源图像
首次覆盖新体素时仍能融合并推进输出时间。回跳会清空两个时间状态，等待新观测后再发布。
语义点云与不确定性点云的发布步长按成功融合帧计数，TF 丢帧、迟到帧和重复源不占用
发布名额，避免持续融合期间因抽样编号恰好落在丢帧上而长期不发布。

## 验证性质与当前边界

测试通过实际 `VoxelMap.update`、三个真实感知回调、投影/TF 重试以及 CARLA 离线
评测入口，验证饱和质量、近零质量、同源复制、新覆盖、不同相机、乱序新源、有限历史、
空窗重现、辅助权重、稳定历史后的可靠纠错和孤立噪声。历史延迟/剪枝组合及无时间戳
调用的回归保留。仿真时钟重启同时覆盖 ROS adapter 与地图。

受控示例分别使用总 alpha 上限 20/200、每次支持 3：100 份稳定旧类别之后，复制低质量
单次噪声不会翻转；随后 10/100 份可靠新源均能纠正，且新类别证据比例超过 0.7。
室内配置仍为总 alpha 上限 200；这些固定数组验证持续更新性质，真实图像的纠错所需
观测量应由匹配实验测定，不照搬测试中的次数。

尚未实现相机视角相似度折扣、有效独立样本量估计或几何遮挡判断。不同源图像不自动
等于独立的新信息。需要固定输入、独立真值与平均/加权平均/旧限幅等基线比较，才能
说明融合收益、查询或导航收益；证据更多、熵更低和测试通过都不能证明这些收益或原创性。
